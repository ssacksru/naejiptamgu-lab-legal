내집탐구 Lab 개인정보처리방침

시행일: 2026-10-04 · 개정: 2026-10-23(실제 쓰는 범위 반영)

내집탐구 Lab(이하 「Lab」)은 유튜브 채널 내집탐구(@naejiptamgu) 운영자 본인이 자기 채널을 관리하려고 쓰는 1인용 도구입니다. 사용자는 채널 운영자 한 명뿐입니다.

1. 접근하는 정보

운영자가 Google 계정으로 허용한 범위 안에서 YouTube Data API를 통해 다음만 사용합니다.

  • youtube.upload — 운영자 본인이 만든 영상을 본인 채널에 업로드하고 제목·설명·공개 설정·예약 시각을 지정
  • youtube.readonly — 운영자 본인 채널의 업로드 목록, 영상 제목, 공개 상태, 예약 공개 시각, 재생목록, 본인 채널 분석 보고서(조회수·시청 지속 등), 본인 채널 영상에 달린 공개 댓글
  • youtube.force-ssl — 본인 영상의 제목·썸네일·예약 시각 수정, 본인 채널 재생목록에 영상 넣기·빼기, 본인 채널 페이지 섹션·채널 예고편 정리

다른 사람의 계정이나 채널에는 접근하지 않습니다. 시청자 정보는 본인 채널에 공개로 달린 댓글(표시 이름·내용)만 읽으며, 운영자가 답할 댓글을 고르는 데에만 씁니다.

2. 보관·처리

인증 토큰과 읽어 온 정보는 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자에게 제공·판매하지 않습니다. 광고·타깃팅 목적으로 쓰지 않습니다. 댓글은 최근 14일분만 임시로 두고 30일 안에 지우며, 통계는 YouTube API 서비스 정책의 보관 기한 안에서 새로 읽어 갱신합니다.

3. Google API 서비스 사용자 데이터 정책

Lab이 Google API로 받은 정보를 사용하는 방식은 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Lab은 YouTube 서비스 약관과 Google 개인정보처리방침을 따르는 YouTube API 서비스를 사용합니다.

4. 권한 취소·삭제

권한은 언제든 Google 계정 › 타사 앱 액세스에서 「내집탐구 Lab」을 삭제해 취소할 수 있습니다. 취소하면 컴퓨터에 남은 토큰은 더 이상 쓸 수 없고, 운영자가 파일을 지웁니다.
