내집탐구 Lab 서비스 약관

시행일: 2026-10-04

1. 무엇인가

내집탐구 Lab(이하 「Lab」)은 유튜브 채널 내집탐구(@naejiptamgu) 운영자가 자기 채널에 직접 만든 영상을 올리고 예약 일정을 확인하려고 쓰는 1인용 내부 도구입니다. 일반에 공개·판매되지 않으며 다른 사용자는 가입하거나 로그인할 수 없습니다.

2. YouTube 서비스 약관

Lab은 YouTube API 서비스를 사용합니다. Lab을 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, 데이터 처리는 Google 개인정보처리방침과 Lab 개인정보처리방침을 따릅니다.

3. 사용 범위

Lab은 운영자 본인 채널에만, 운영자가 권리를 가진 영상만 올립니다. YouTube 데이터를 수집·재배포하거나 다른 채널에 접근하지 않습니다.

4. 권한 취소

Google 계정 › 타사 앱 액세스에서 언제든 취소할 수 있습니다.
