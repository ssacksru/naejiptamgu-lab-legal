내집탐구 Lab

내집탐구 Lab은 YouTube 채널 내집탐구(@naejiptamgu) 운영자가 자기 채널의 쇼츠 업로드·예약 일정을 관리하려고 직접 만든 1인용 내부 도구입니다. 일반 사용자에게 제공되는 서비스가 아닙니다.

YouTube API 서비스를 사용합니다 — 운영자 본인 채널의 예약 목록 읽기(youtube.readonly)와 본인 영상 업로드(youtube.upload)만 합니다.
